# Ports removed by the duplicate prune

Each port name is kept in exactly one tree, chosen by this precedence:

1. ports/core, ports/extra, ports/contrib, ports/multilib (lfs-scripts own)
2. ports/scratch/venom-{core,extra,nonfree,multilib,kde-lxqt,mate,xfce}
3. ports/scratch/{opt,core,xorg,plasma,gnome,compat-32,lxqt,xfce,kde4,compiz,contrib,iso}

The paths below were removed; the surviving copy of each port lives in a
higher-precedence tree. `git log --diff-filter=D -- <path>` recovers one.

The venomlinux recipes have since been imported into the local trees
(ports/{core,extra,multilib,nonfree,mate,xfce,kde-lxqt,s6}) and the venom-*
directories are gone, so every ports/scratch/venom-* entry below is historical:
those recipes now live in the local trees, and a name a local tree already
provided was not overwritten.
